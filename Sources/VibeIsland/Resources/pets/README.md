# Codex pet sprite sheets

This folder is intentionally empty in the repository.

The Codex mascots are OpenAI's official "Codex Pets" sprite sheets. They are
**not redistributed here**; run `scripts/fetch-pets.sh` to download them into
this folder before building if you want the animated Codex pet.

Without them the app still builds and runs — Codex sessions simply fall back to
the same pixel mascot used for Claude sessions.
